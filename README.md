# Sri Nidhi K — Portfolio Website

A modern, responsive, full-stack developer portfolio built with **React** and **Vite**.

## Features

- ⚡ **Fast & Lightweight**: Built with Vite and React.
- 🌙 **Dark / Light Theme Toggle**: Persistent custom styling with CSS variables.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- 🚀 **Automated GitHub Pages Deployment**: Built-in GitHub Actions workflow.
